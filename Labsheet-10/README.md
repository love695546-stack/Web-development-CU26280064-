# MCA108P Lab Sheet 10 Solutions

This repository contains full production-grade implementations for all 20 questions in MCA108P Lab Sheet 10.

## Project Structure
- `config/`: Database singleton setup
- `controllers/`: MVC Controllers & RESTful APIs
- `models/`: Database models & CRUD operations
- `public/`: Web root with Front Controller (`index.php`) and `.htaccess`
- `views/`: Reusable header/footer templates & views
- `scripts/`: Git, Apache, SSL, MySQL, and Security setup scripts
