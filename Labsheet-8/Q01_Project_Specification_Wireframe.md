# Question 1: Project Specification & Wireframe Layout Document

## Client Profile: Eco-Friendly Artisan Café ("Green Leaf Café")

### 1. Project Overview & Objectives
- **Target Audience:** Health-conscious individuals, eco-friendly consumers, coffee lovers, and local remote workers.
- **Key Offerings:** Organic coffee, artisan bakery products, eco-conscious daily menu, and table reservations.
- **Core Goal:** Provide a responsive, accessible, and high-performance multi-page web application showcasing offerings, customer testimonials, and an online booking form.
