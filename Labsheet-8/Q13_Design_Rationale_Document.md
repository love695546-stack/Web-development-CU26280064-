# Question 13: Comprehensive Design Rationale Document

## 1. Color Palette Selection & Psychology
- **Primary Color (#2d6a4f - Deep Emerald):** Symbolizes organic freshness, sustainability, and eco-friendly brand alignment.
- **Secondary Color (#d8f3dc - Mint Tint):** Provides a soothing, clean background highlight promoting calm readability.
- **Accent Color (#e9c46a - Warm Gold):** Highlights Call-To-Action (CTA) reservation buttons.

## 2. Typography Alignment
- **Heading Font:** Playfair Display / Serif — Conveys artisan craftsmanship and premium quality.
- **Body Font:** Segoe UI / System Sans-Serif — Guarantees maximum legibility across mobile devices.

## 3. Target Audience Alignment
- Tailored for health-conscious urban professionals seeking fast, accessible table booking and organic menu browsing.
