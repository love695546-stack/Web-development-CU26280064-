# Question 17: Local Test Environment Setup Guide

## Hosting Local Web Applications via Apache & XAMPP

1. **Install & Launch XAMPP:**
   - Download XAMPP v8.2.12 for Windows 64-bit Enterprise OS.
   - Open XAMPP Control Panel and start the **Apache** web server module.

2. **Project Directory Deployment:**
   - Move the project directory `portfolio_cafe` into `C:\xampp\htdocs\`.

3. **Accessing Local Environment:**
   - Open any modern browser (Chrome/Edge) and navigate to:
     `http://localhost/portfolio_cafe/index.html`

4. **Port Configuration:**
   - Ensure Apache default port `80` / SSL `443` is unblocked in Windows Firewall.
